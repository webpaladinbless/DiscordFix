>
> Добавьте папку с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). При уверенной настройке исключений предпочтительно добавить исключение; если вы не вполне понимаете последствия, рекомендуется отключить детектирование PUA.

## ⚙️ Установка и запуск

1. Сначала включите Secure DNS (Безопасный DNS).
   * В Chrome активируйте "Использовать безопасный DNS" и выберите провайдера, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
   * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/webpaladinbless/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, загруженных через 7-Zip или PeaZip, этот пункт можно пропустить.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл:
   * Чтобы найти рабочую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Для запуска стратегии вместе с системой в **`service.bat`** выберите `Install Service`, а затем нужную стратегию.

## ℹ️ Что делают файлы и пункты меню

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому перебирайте разные варианты — **ALT, FAKE и другие**, пока не найдёте подходящий для себя.

- [**`service.bat`**](./service.bat) объединяет установку автозапуска, диагностику, тестирование и обновление:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб.
  - **`Check Status`** — показывает состояние обхода и служб: автозапущенной стратегии и WinDivert.
  - **`Game Filter`** — меняет режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
    **После изменения режима стратегию нужно перезапустить.**  
    В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — управляет обходом ресурсов из `ipset-all.txt`. Это полезно при проверке ресурса, который без zapret открывается, а с ним — нет.  
    Текущий режим указывается в скобках:
    - `none` — ни один IP не проверяется;
    - `loaded` — IP сопоставляется со списком;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включает или выключает автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменяет используемый фейк на другой файл из `bin`.
  - **`Update IPSet List`** — загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** — ищет распространённые причины неисправности zapret.  
    В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение неожиданно перестало работать.
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` тестирует DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/webpaladinbless/zapret-discord-youtube/issues/522).

### Не нашлась подходящая стратегия

1. Откройте командную строку с правами администратора.
2. Выполните команды по очереди:

   `netsh winsock reset`
  
   `netsh int ip reset all`
  
   `netsh winhttp reset proxy`
  
   `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущая версия hosts устарела, программа предложит обновить файл вручную:  
- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора;
- вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки;
- сохраните файл и проверьте подключение. Если результата нет, убедитесь, что hosts действительно был сохранён.

#### Работа не гарантируется. Если способ не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/webpaladinbless/tg-ws-proxy) или с любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии со временем могут терять работоспособность.**
> То, что некоторое время работало, может перестать работать после обнаружения стратегии.
> Здесь собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

Проверьте следующее:

- в `service.bat` -> `Run Diagnostics` не должно быть ошибок;
- адрес нужного ресурса должен присутствовать в списках доменов или IP;
- попробуйте другие варианты, в том числе **`ALT`** и **`FAKE`**;
- выполните полную переустановку по инструкции ниже;
- ознакомьтесь с [#765](https://github.com/webpaladinbless/zapret-discord-youtube/issues/765).

### Полное обновление или переустановка

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Затем выполните `service.bat` -> `Run Diagnostics`; при наличии ошибок устраните их, а в конце выберите Y.
- Удалите папку с zapret.
- Скачайте последнюю сборку со [страницы релизов](https://github.com/webpaladinbless/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву, откройте свойства и, если внизу справа есть пункт разблокировки, нажмите его, затем `Применить` -> `ОК`.
- Распакуйте архив в новую папку в корне диска. В её пути не должно быть специальных символов и пробелов.
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если выбранная стратегия не работает, закройте программу через значок замка на панели задач и попробуйте следующую.
- После выбора рабочей стратегии установите её в автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

Инструкция доступна [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся в службах

1. Узнайте имя службы в командной строке Windows. Открыть её можно через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-установка-и-запуск).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежняя стратегия перестала работать, переберите остальные.
- Дополнительная информация есть в [#251](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8F-установка-и-запуск) настроен.
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить именно её.
- Вызовите `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Проверьте, заработало ли приложение после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте все стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/webpaladinbless/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/webpaladinbless/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальный порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: при `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите все IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема останется, создайте обсуждение в разделе [Discussions](https://github.com/webpaladinbless/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

Создайте обращение [здесь](https://github.com/webpaladinbless/zapret-discord-youtube/issues).

## 🗒️ Как добавить адреса других ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
